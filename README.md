Project Name: WH40K Media Tracker

1. Project Overview

This is meant to give a visual representation of Warhammer 40k media (novels, codex, games, etc.) and how different aspects are connected (eras, events, series, etc.)

Purpose: Finding what to consume next in 40k can sometimes be challenging, this is meant to assist with this process.
Objective: Help find which piece of media to consume next or help find all media related to a specific character/event/group.
Target Audience: Me

2. Project Description

Users will be able to filter through different eras/factioins/media types/characters/locations or view all events at once. All pieces of media regarding the filters will be displayed in chronological order
    to help users track where to jump into. Users will be able to zoom in and out and drag around the display to get better looks at each different part. Users will also be able to click into different 
    "components" to get more information on those specifics.

3. Requirements

3.1 Functional
    1. Faction filters (humanity, choas, xenos, etc.)
    2. Media order chronologically in differnt shapes (rectangle - books; circles - characters; etc.) with "lines" connecting medias
    3. "profiles" for each piece of media (release date, main characters, faction, etc.)
